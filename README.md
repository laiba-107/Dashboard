✨ **An interactive visualization tool** for learning algorithms and data structures through step-by-step animations and visual demonstrations.

![Dashboard Screenshot](https://i.imgur.com/JQ8K3hG.png)

## 🌟 Features

### 🔍 Visual Learning
- Step-by-step animations with color-coded operations
- Detailed explanations of each algorithm's process
- Visual representation of time and space complexity

### 📊 Comprehensive Coverage
| Category        | Algorithms/Structures Included          |
|-----------------|-----------------------------------------|
| **Searching**   | Linear Search, Binary Search            |
| **Sorting**     | Bubble Sort, Merge Sort, Quick Sort, Heap Sort, Insertion Sort, Counting Sort, Radix Sort |
| **Trees**       | BST, AVL Tree, Red-Black Tree           |
| **Graphs**      | BFS/DFS, Dijkstra's, MST, Floyd-Warshall |
| **Data Structures** | Stack, Queue, Linked List, Hash Table |

### 🛠️ Interactive Elements
- Adjustable parameters (array sizes, speeds)
- Real-time performance metrics
- Side-by-side algorithm comparisons
